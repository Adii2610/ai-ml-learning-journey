# Week 3: Python Object-Oriented Programming (OOP)

This week covers the core concepts of Object-Oriented Programming in Python. 

## Topics Covered:
- **Day 1:** Classes and Objects
- **Day 2:** Constructors (`__init__`) and Methods
- **Day 3:** Encapsulation (Protecting data)
- **Day 4:** Inheritance (Reusing code)
- **Day 5:** Polymorphism and Abstraction
- **Day 6:** Final Project (Library Management System)

Each folder contains practical scripts to demonstrate these concepts.
